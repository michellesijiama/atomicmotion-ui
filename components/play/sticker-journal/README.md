# Sticker Journal

A hobonichi-style sticker journal on a portrait phone, a page of warm cream paper with a faint dot grid and a hand-lettered date above a sheet of die-cut stickers. Swipe the sheet through four packs, café treats, garden friends, little words and washi tape, then tap a sticker to watch it peel off, fly across and land on the page with a squash, or drag one there yourself. Drag a stuck sticker to move it, pull its corner to turn and resize it, and nudge it from the keyboard. Every sticker is drawn in code as inline SVG, flat pastel colour and plum ink inside a thick white cut line

## Usage

Save this example beside the copied source file, or adjust the relative import to its new location:

```tsx
"use client";

import { StickerJournal } from "./sticker-journal";

export function Demo() {
  return (
    <div className="@container h-[36rem] w-full">
      <StickerJournal />
    </div>
```

The wrapper provides a bounded preview area. Resize it or pass `className` to fit your app. Leave demo `loop` mode off when you want manual interaction (see defaults below).

## Props

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `loop` | `boolean` | `false` | Gallery card: swipe to a pack, peel a sticker onto the page, now and then turn one, and start over once the page is full, until the user interacts. |
| `date` | `string` | `"Oct 29 · Thu"` | The hand-lettered date at the top of the page. Defaults to a fixed date so SSR and gallery posters are deterministic. |
| `initialStickers` | `PlacedSticker[]` | `DEFAULT_STICKERS` | The stickers the page starts with. Defaults to a small spread of four so the page is never bare. |
| `onChange` | `(stickers: PlacedSticker[]) => void` | — | A person placed, moved, turned, resized, removed or cleared stickers. Receives the whole page, back to front. |
| `className` | `string` | — | Additional classes for the root container. |

Named export: `StickerJournal`. Public types: `StickerId`, `PlacedSticker`, `StickerJournalProps`.
