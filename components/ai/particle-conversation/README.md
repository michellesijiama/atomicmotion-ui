# Particle Conversation

A blue particle field and a monochrome waveform react to music or a microphone inside a black landscape card.

![Particle Conversation preview](https://atomicmotion.dev/previews/particle-conversation.png)

- **Category:** AI
- **Demo:** https://atomicmotion.dev/components/particle-conversation
- **Dependencies:** framer-motion, lucide-react

## Setup

Use React 19, TypeScript and **Tailwind CSS 4**. Class names use v4 features, including container queries; Tailwind v3 is not a drop-in equivalent.
Enable Tailwind in your app stylesheet (`@import "tailwindcss";`) and make sure it scans the folder where you copy the component. See [the integration guide](../../../docs/COPY-PASTE.md).

Install the compatible dependency ranges tested by this repository:

```bash
npm install framer-motion@^12.40.0 lucide-react@^1.18.0
```

## Usage

Save this example beside the copied source file, or adjust the relative import to its new location:

```tsx
"use client";

import { ParticleConversation } from "./particle-conversation";

export function Demo() {
  return (
    <div className="@container h-[36rem] w-full">
      <ParticleConversation />
    </div>
  );
}
```

The wrapper provides a bounded preview area. Resize it or pass `className` to fit your app. Leave demo `loop` mode off when you want manual interaction (see defaults below).

## Props

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `defaultAudioUrl` | `string` | — | Optional same-origin audio track played on activation. |
| `defaultAudioTitle` | `string` | — | Display name for the demo track. |
| `defaultAudioStart` | `number` | `0` | Start position, in seconds, for the optional audio track. |
| `defaultAudioClimax` | `number` | — | Optional downbeat, in seconds, after the track's buildup. |
| `showNarrative` | `boolean` | `true` | Show a title, an audio meter and captions for the demo. |
| `story` | `{ captionDuration: number; artist: string; cover: string; }` | — | Timing and artwork for the demo track. |

Named export: `ParticleConversation`. Public types: `ParticleConversationProps`.
